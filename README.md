# Georgia Currency Tracker 🇬🇪

A simple Python script that fetches the live Israeli Shekel (ILS) to Georgian Lari (GEL) exchange rate using the ExchangeRate-API.

## Setup Instructions

1. Clone this repository.
2. Install the required dependencies:
   `pip install requests python-dotenv`
3. Get a free API key from [ExchangeRate-API](https://www.exchangerate-api.com/).
4. Create a `.env` file in the root directory and add your key:
   `EXCHANGE_API_KEY=your_api_key_here`
5. Run the script:
   `python tracker.py`
